# Student Performance Analytics System

## 1. Project Description
The Student Performance Analytics System is a Python-based project used to analyze student marks, grades, results, and attendance. It helps summarize student performance and identify top-performing students.

## 2. Objective
The main objective is to use Python, NumPy, and Pandas to organize student data and perform basic academic performance analysis.

## 3. Technologies Used
- Python
- NumPy
- Pandas
- CSV dataset
- Visual Studio Code

## 4. Dataset Description
The project uses a CSV file named `students.csv` containing 20 student records.

The dataset includes:
- Student ID
- Name
- Department
- Python marks
- DBMS marks
- Java marks
- Attendance percentage

## 5. Key Features
- Loads student data from a CSV file.
- Calculates total and average marks.
- Assigns grades based on average marks.
- Identifies pass and fail results.
- Calculates class performance statistics.
- Performs subject-wise analysis.
- Identifies the top three students.
- Analyzes student attendance.

## 6. Grading and Result Rules
Grades are assigned using the following average-mark ranges:
- A: 90 and above
- B: 80 to below 90
- C: 70 to below 80
- D: 60 to below 70
- F: Below 60

A student passes if they score at least 40 marks in every subject. Otherwise, the result is Fail.

## 7. Project Files
- `main.py` — contains the Python program.
- `students.csv` — contains the student dataset.
- `README.md` — contains project documentation.

## 8. How to Run the Project
1. Install Python.
2. Install the required libraries using `python3 -m pip install pandas numpy`.
3. Keep `main.py` and `students.csv` in the same folder.
4. Open the terminal in the project folder.
5. Run `python3 main.py`.

## 9. Learning Outcomes
Through this project, I practiced Python functions, loops, conditional statements, NumPy calculations, Pandas DataFrames, CSV file handling, and basic data analysis.

## 10. Final Outcome
The system successfully analyzes 20 student records and displays marks summaries, grades, results, class statistics, subject-wise performance, top performers, and attendance analysis.
